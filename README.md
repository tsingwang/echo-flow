> ⚠️ **本工具不提供任何教材音频或课文内容。** 音频（mp3）与字幕（lrc）需由你自行导入合法拥有的资源，导入的文件仅保存在你本机浏览器（IndexedDB），不会上传服务器。

## 核心功能

- **自带资源导入**：支持文件夹批量 / 多选文件 / zip 包三种方式导入你自己的 mp3+lrc
- **合集字幕导出**：首页“导入”左侧的“导出”将当前合集的全部 `.lrc` 打包为一个 ZIP 下载，不含音频，压缩包以合集名称命名。导出使用当前保存的字幕文本，保留上传时的头部标签、未编辑的内容和最新的句子修改。新导入的字幕保留原始文件名（含扩展名大小写）；此前导入的旧资源未记录完整字幕文件名，按原课文件名加 `.lrc` 导出。包内字幕编码为 UTF-8，支持中文文件名，导出的 ZIP 可直接重新导入。
- **合集管理**：首页 EchoFlow 标题和提示下方以按钮式 Tab 切换合集，紧跟最后一个标签的 `+` 按钮可打开创建弹窗；标签较多时整栏可横向滚动。电脑端可拖动 Tab 调整顺序，也可聚焦标签后按 `Alt + ← / →` 移动，顺序自动保存在当前浏览器，刷新后保留，新合集追加到末尾；排序不切换当前合集。必须先创建合集才能导入，不提供默认合集，也不迁移旧版资源。导入只进入当前合集，不同合集中的同名文件互不覆盖。学习页仅显示课文标题和学习内容，不显示 EchoFlow 标题或合集 Tab；点击“首页”返回当前合集，再切换或创建合集。合集和资源均仅保存在当前浏览器，不随学习数据备份或服务端同步迁移。
- **句子级点读**：点击任意句子开始播放，自动高亮跟随；在句子上使用 ←/→ 切换时，键盘焦点同步移动，随后按 `E` 编辑切换后的句子。聚焦句子沿用当前句子的单条边框（浅色主题为深灰色，深色主题为米灰色），不叠加蓝色外框或投影，Tab 切换与左右切句时边框即时更新。
- **句子编辑**：选中句子或用 Tab 聚焦句子后按 `E`，可编辑英文、中文和开始时间，时间框左右按钮每次减/加 100ms。打开窗口时默认聚焦时间框的减号按钮。编辑框和修改后的 LRC 时间戳统一使用 `mm:ss.SSS`（如 `01:23.456`，分钟至少两位、小数三位）；兼容原字幕中两位与三位小数混用（`.12` 与 `.120` 均为 120ms），未编辑的原始行保持不变。时间须严格位于前后句之间，首句可从 0 开始，不能超出已知音频时长。打开编辑时暂停播放；关闭按钮、Esc 或点击遮罩会保存，输入无效或保存失败时保留弹窗并提示。修改仅保存到当前浏览器的 IndexedDB，不改动原始 LRC 文件，也不随学习数据备份或服务端同步迁移；快捷键可在设置中修改。
- **多语言视图**：EN / EN+CN / CN 三种显示模式
- **播放控制**：默认倍速为 1×，手动选择的倍速会保留；支持倍速调节、连读/点读切换、循环模式、断点续播；学习页底部播放器的当前时间和总时长以 `分:秒.毫秒` 显示（如 `1:23.456`），实际时间精度取决于浏览器。
- **全局快捷键**：空格播放/暂停，↑/↓ 增加/减少音量（每次 10%，显示音量百分比并记住设置），←/→ 上一句/下一句，Ctrl+←/→ 上一课/下一课；支持自定义键位及组合键。
- **学习管理**：句子收藏、学习记录、进度追踪
- **收藏播放**：优先播放已导入课程的原音频，按当前 LRC 的时间定位，到原文下一句开始处停止（末句播至音频结束），不以“下一条收藏”作为结束点。支持暂停/继续、倍速与当前分类循环；资源缺失时仅将对应句子的“原文”按钮改为不可点击的“缺失”，不额外提示，并使用浏览器 TTS 朗读。音色设置仅影响 TTS，不改变原音频；浏览器阻止自动播放时需点击播放重试。
- **原文返回**：从收藏页点击“原文”进入课文时，左上角显示“返回”，点击回到收藏页；从首页等其他入口进入时仍显示“首页”。收藏页左上角固定为“首页”，直接打开首页，不使用浏览器后退，避免与原文页来回跳转。来源标记保存在链接片段中，刷新、切换相邻课文或自动播放下一课时仍保留，不影响离线资源缓存。
- **收藏分类**：收藏页顶部按“全部”和各合集过滤，显示各分类数量；合集顺序沿用首页，不在收藏页提供排序。已删除合集或旧资源的收藏归入“已删除合集”。切换分类会停止播放，播放、切句和循环仅针对当前分类。快捷键直接复用学习页配置，不增加设置项：默认 `Space` 播放/暂停、`R` 重播当前句、`← / →` 切换前后句、`↑ / ↓` 调节音量（每次 10%）；在学习页自定义过的对应按键同样生效，音量设置也共享。原音频和 TTS 均适用；TTS 调音量会从句首重播，暂停时仍保持暂停。输入框、弹窗及合集标签内不触发。逐句移除或设置里的“清空收藏”只影响当前分类，选择“全部”时才会清空所有收藏。
- **单课删除**：首页课程卡片右侧的垃圾桶替代原课文收藏星标，桌面端悬停卡片或键盘聚焦时显示，触屏设备保持可见。点击后显示课程名称和文件名，确认才会删除当前合集这一课的音频、LRC 和学习记录；取消或 Esc 不删除。删除后合集和其他课程不受影响，句子收藏与设置保留，不修改电脑原始文件。删除前请关闭该课程的其他学习页面；若启用了服务端同步，对应学习记录的清空也会同步到服务端。
- **按合集清理**：首页点击“清理”打开确认弹窗，确认后删除当前合集（包括 Tab、名称、音频、字幕和学习记录），其他合集不受影响，句子收藏、课文收藏及设置会保留；不会删除电脑上的原始文件。删除后自动切换到剩余合集；没有合集时需重新创建才能导入。已删除合集的收藏文本仍可查看和使用语音合成朗读，但原资源链接会失效。清理前请关闭其他学习页面，避免旧页面重新写入进度；若启用了服务端同步，对应学习记录的清空也会同步到服务端。
- **现代界面**：Apple 风格、深浅色主题（浅色采用暖米色背景 `#f5f0e8` 与深灰文字 `#3a3a3a`；深色采用暖炭灰背景 `#1c1b18`、米灰文字 `#d8d1c3` 和低饱和暖金色强调，减少纯黑与亮白的强烈反差）、响应式设计
- **零依赖**：纯静态文件，解压即用

## 快速开始

### 方式一：Docker 一键部署（最简单）

只需一条命令，无需下载代码：

```bash
docker run -d -p 8080:80 --name echo-flow --restart unless-stopped luzhenhua/echo-flow:latest
```

然后访问 `http://localhost:8080` 即可！

**自定义端口：**
```bash
docker run -d -p 3000:80 --name echo-flow --restart unless-stopped luzhenhua/echo-flow:latest
```

详细的 Docker 部署说明请查看 [DOCKER.md](DOCKER.md)

### 方式二：Docker Compose 部署

适合需要自定义配置的场景：

```bash
# 克隆项目
git clone https://github.com/luzhenhua/echo-flow.git
cd echo-flow

# 启动服务
docker-compose up -d

# 访问 http://localhost:8080
```

### 方式三：本地开发服务器

1. **下载源码**：`git clone https://github.com/luzhenhua/echo-flow.git`（或从仓库页面下载 zip）
2. 启动本地服务器：

   **方法一：使用Python**
   ```bash
   # 在解压后的文件夹中打开终端，运行：
   python -m http.server 8000
   # 然后访问：http://localhost:8000
   ```
   注：部分 Python 版本自带的 `http.server` 不支持 HTTP Range 请求，可能导致“点击句子跳转会从头播放”；建议优先使用下面的 Node/Docker/NGINX 等方式。

   **方法二：使用Node.js**
   ```bash
   # 在解压后的文件夹中运行：
   npx serve .
   # 然后访问显示的本地地址
   ```

   **方法三：使用VSCode的Live Server插件**
   - 安装Live Server插件
   - 右键点击 `index.html`，选择"Open with Live Server"

3. 在浏览器中打开显示的本地地址，开始学习！

**注意**：不能直接双击 `index.html` 文件，会因为浏览器安全策略导致无法加载数据文件。
